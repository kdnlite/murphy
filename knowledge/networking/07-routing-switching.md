# Routing aur Switching

## Switch
Ek hi local network (LAN) ke andar devices ko jodta hai. MAC address dekh kar data
sahi device ko bhejta hai. Switch ek building ke andar ke kamron ke beech daak
baantne wala samjho.

## Router
Alag-alag networks ko jodta hai (jaise aapka ghar aur internet). IP address dekh
kar best raasta chunta hai. Router sheher-sheher ke beech daak bhejne wala samjho.

## Routing table
Router ke paas ek table hoti hai: "is network ke liye data us raaste jaayega".
Jab packet aata hai, router table dekh kar agla hop chunta hai.

## NAT (Network Address Translation)
Ghar ke bahut se private IP waale devices ek hi public IP se internet chalate hain.
Router andar-bahar ke pate badal-badal kar sahi device tak jawaab laata hai.

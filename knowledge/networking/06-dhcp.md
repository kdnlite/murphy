# DHCP

DHCP (Dynamic Host Configuration Protocol) naye device ko apne-aap network ki
settings de deta hai, taaki use haath se kuch na bharna pade.

## Kya deta hai
- IP address
- Subnet mask
- Default gateway (router)
- DNS server

## Process (DORA)
1. Discover: device poochta hai "koi DHCP server hai?"
2. Offer: server ek IP offer karta hai.
3. Request: device woh IP maangta hai.
4. Ack: server pakka kar deta hai.

Ghar ke router mein hi aam taur par DHCP server hota hai. Isi liye naya phone WiFi
se judte hi internet chalne lagta hai.

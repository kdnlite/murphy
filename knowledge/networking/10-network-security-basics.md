# Network security ki buniyaad (bachaav)

Yeh hissa network ko surakshit rakhne ke baare mein hai — hamla karne ke baare mein
nahi.

## Apna WiFi surakshit rakhna
- Mazboot, lamba WiFi password rakho; WPA3 (ya kam se kam WPA2) on rakho.
- Router ka default admin password turant badlo.
- Router ka firmware update rakho.
- Guest network alag rakho, taaki mehmaan aapke main network tak na pahunchein.
- WPS band rakho (purana aur kamzor).

## Encryption
- HTTPS (TLS): website se data encrypt hota hai, beech mein koi padh nahi sakta.
  Browser mein taala (lock) iska ishaara hai.
- VPN: aapke saare traffic ko ek surakshit surang se bhejta hai.

## Firewall
Network mein aane-jaane wale traffic ko niyam ke hisaab se rok ya allow karta hai.
Ghar ke router mein ek basic firewall hota hai.

## Aam khatre aur bachaav
- Phishing: nakli email/website jo password churaati hai. Link soch-samajh kar
  kholo, address dekho.
- Public WiFi par banking se bacho ya VPN use karo.
- Software aur devices ko update rakho — purani kamzoriyan isi se bandh hoti hain.
- Do-step verification (2FA) on rakho.

Yeh sab defensive (bachaav) kaam hain. Murphy kisi doosre ke network ya device
mein bina ijaazat ghusne mein madad nahi karta.
